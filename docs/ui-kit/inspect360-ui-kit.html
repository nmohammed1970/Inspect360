Inspect360 UI Kit

Portable design system extracted from Inspect360 — tokens, buttons, badges, cards, inputs, tabs. Open this file in a browser or copy the :root CSS into another project.

How to reuse in another project

  1. Copy the entire :root { … } block from this file’s <style> into your global CSS.
  2. Copy the component classes you need (.btn-*, .badge-*, .card, .input, .tabs).
  3. Fonts: load Inter (body) + Poppins (headings), or swap for your brand fonts.
  4. In React/Tailwind projects, map these HSL tokens to tailwind.config the same way Inspect360 does in client/src/index.css.
  5. Primary CTA pattern: use .btn-brand (teal gradient), not flat navy.
